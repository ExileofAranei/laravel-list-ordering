# 06 — Конкурентность: ретрай с перерезолюцией якорей

**What to build:** конфликт уникального индекса при параллельной вставке в один и тот же промежуток не падает пользователю — вызывается ограниченный ретрай, который каждый раз заново резолвит соседей из БД.

**Blocked by:** 04

**Status:** ready-for-agent

- [x] `Positioner` принимает `maxRetries` параметром конструктора (не конфиг-файл), значение по умолчанию — 3; переопределяется биндингом в контейнере
- [x] На конфликт уникальности при записи — повтор до `maxRetries` раз; **каждая** попытка заново резолвит недостающие якоря SELECT'ом по индексу, а не перегенерирует ранг между границами предыдущей попытки (переиспользование старых границ детерминированно воспроизвело бы тот же конфликт — это условие сходимости, не оптимизация)
- [x] Исчерпание ретраев → `Exceptions\RankConflictException`
- [x] Тест: форсированный конфликт на первой попытке (тестовый дубль `RankGenerator`, возвращающий уже занятый ранг один раз) — операция успешно завершается через ретрай
- [x] Тест: ретрай действительно перерезолвит якорей заново (не просто перегенерирует ранг в тех же границах) — через подмену состояния соседей между попытками (побочный эффект внутри тестового дубля генератора: вставляет конкурирующую строку на первом вызове) и проверку зафиксированных границ на обоих вызовах

Дополнительно (не в чек-листе, но напрямую проверяет заявленное): тест на фактическое исчерпание ретраев (`RankConflictException` при генераторе, всегда возвращающем занятый ранг) и тест на переопределение `maxRetries` через биндинг контейнера.

**Находка вне тикета:** `illuminate/database` и `illuminate/support` использовались в `src/` напрямую (`Model`, `Builder`, `Blueprint`, `Facades\DB`), но не были объявлены в `composer.json` — только `illuminate/contracts`. Работало только благодаря транзитивной подтяжке через dev-зависимости. Добавлены оба в `require` тем же диапазоном версий, что и `illuminate/contracts`. Обнаружено при добавлении `Illuminate\Database\UniqueConstraintViolationException` в `Positioner`.
